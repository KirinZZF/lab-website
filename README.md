# Intelligent Condition Monitoring for Energy and Power Systems website

Website of the Intelligent Condition Monitoring for Energy and Power Systems group
(Dr Xiandong Ma), School of Engineering, Lancaster University.

**Live site:** https://kirinzzf.github.io/lab-website/

Built with [Jekyll](https://jekyllrb.com/) and hosted free on GitHub Pages.
People, publications, news and research themes are plain YAML files in
`_data/`, so most updates are a one-file edit in the browser.

**To update the site, read [MAINTAINING.md](MAINTAINING.md).**

Site created in 2026 by Zhefeng Zhang.
